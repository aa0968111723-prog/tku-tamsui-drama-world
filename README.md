# 淡江·淡水 · 虛擬劇本世界

> Tamkang × Tamsui Drama World

這是可持續開發的**劇本世界工程**（World as Code）。

## 結構

```
world/
  world.json          # 世界狀態（地點、角色、集數）
  SCRIPT.md           # 人類可讀劇本
  LOCATIONS.md        # 場景聖經
  CHARACTERS.md       # 角色卡
  DEVLOG.md           # 開發日誌
```

## 設定

- 地區：新北市淡水
- 校園：淡江大學淡水校園
- 基調：青春成長 × 校園神秘 × 地方人情
- 時代：當代

## 第一集

**第一集：宮燈下的迎新**

新生安倢踏入淡江，卻發現柏能學長在驚聲廣場失聯——一場橫跨校園與淡水的尋人劇本就此展開。

## 持續開發

1. 在虛擬世界編輯器調整場景／對白
2. 匯出並 commit 到本 repo
3. 開 PR 擴充第二集、支線、新地點

## 線上編輯器

本世界對應 Grok 上的「淡江·淡水 · 虛擬劇本世界」App：

- 首頁：世界編輯器
- `/play`：3D 校園闖關體驗
